# 🔴 Connect Four 🟡

A browser-based, two-player Connect Four game built with HTML, CSS, and JavaScript. Players take turns placing colored disks on a 7×6 board, with the objective of connecting four disks of their own color.

## ✨ Features

- 👥 **Two-Player Gameplay:** Supports two human players taking turns on the same board.
- 🟡 **Player One:** Uses yellow disks.
- 🔴 **Player Two:** Uses red disks.
- 🏆 **Win Detection:** Automatically detects when a player connects four disks horizontally, vertically, or diagonally.
- 📊 **Statistics:** Keeps track of each player's wins, losses, and draws.
- 🎉 **Winner Display:** Shows a congratulatory message when a player wins.
- 🔄 **Board Reset:** Allows players to clear the board and start a new round.

## 🎮 How to Play

1. Player One uses yellow disks, while Player Two uses red disks.
2. Players take turns selecting positions on the board.
3. Disks can only be placed in positions supported by another disk or the bottom of the board.
4. The objective is to connect four disks of the same color horizontally, vertically, or diagonally.
5. The first player to connect four disks wins!

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Launch `index.html` using a browser or a local development server such as VS Code Live Server.
4. Start playing!

## 🚧 Possible Improvements

The game is functional, but there are several areas that could be improved:

- 🤝 **Automatic Draw Detection:** Automatically detect when the board is full and neither player has won.
- 🛑 **Post-Victory Input Prevention:** Prevent players from placing additional disks after someone has won.
- 🔄 **Improved Round Management:** Automatically prepare the board for a new round after a game ends.
- 📱 **Responsive Design:** Adapt the board and statistics panel to different screen sizes and devices.
- 🎨 **Visual Improvements:** Improve the interface, animations, and overall gameplay experience.
- 🧹 **Code Optimization:** Refine the JavaScript logic and improve code organization.
